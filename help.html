Welcome to the official portal of the Arunachal Pradesh Administrative Reforms Commission. This section provides assistance on browsing the portal and accessing government documents.

Viewing Information in Various File Formats

Documents provided on this portal are primarily in HTML and Portable Document Format (PDF). To view PDF files smoothly, modern web browsers include native PDF preview capability. You may also install Adobe Acrobat Reader or any standard free PDF viewer.

Text Resizing & Accessibility Tools

On every page, you can use the top right accessibility buttons:

  • Decrease Text (A-): Decreases page font size for smaller screens.
  • Normal Text (A): Resets font size to the standard baseline (100%).
  • Increase Text (A+): Enlarges font size up to 120% for enhanced legibility.

Submitting Suggestions

To submit your recommendations on administrative governance, visit our Suggestions & Feedback page or interact on the APARC Citizen Forum.
